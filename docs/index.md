# AdaGScale

## Viewpoint-Adaptive Gaussian Scaling in 3D Gaussian Splatting to Reduce Gaussian-Tile Pairs

Accepted at DAC 2026.

AdaGScale is a viewpoint-adaptive Gaussian scaling
method that accelerates 3D Gaussian Splatting
by reducing unnecessary Gaussian-tile pairs.

- [Source Code on GitHub](https://github.com/askmgk/AdaGScale)
- [Paper on arXiv](https://arxiv.org/abs/2604.18980)
